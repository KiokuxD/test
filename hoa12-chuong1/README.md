## Tính năng

5 tab:

| Tab | Nội dung |
|-----|----------|
| 📚 **Lý thuyết + Bài tập** | 21 mục lý thuyết chi tiết (24 ví dụ mẫu có lời giải + 50 bài tự luyện có đáp án), kèm **21 mẹo nhớ inline** |
